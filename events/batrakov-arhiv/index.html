«Claude Code для непрограммистов»

Практический воркшоп: как начать пользоваться Claude Code без навыков программирования — от установки до первого рабочего результата.

Игорь Батраков
ИТ-директор компании «Спектрасофт», предприниматель и специалист по ИИ

Как работать с Claude Code

Полная инструкция по установке, настройке и безопасному использованию — собрали по итогам встречи.

01 / Зачем вам Claude Code

Claude Code — это инструмент, который позволяет людям без навыков программирования создавать работающие программы, автоматизировать рутинные задачи и строить продукты с помощью AI. Вы описываете задачу обычным языком — Claude сам пишет код, запускает его, исправляет ошибки и доводит до результата.

Это называется вайб-кодингом — подходом, при котором не нужно уметь писать код вручную. Вы становитесь постановщиком задачи и проверяете результат, а Claude делает техническую работу.

Что можно сделать на практике

Автоматизация рутины

Автоматически переименовать тысячу файлов по правилу, собрать таблицу из данных нескольких источников, отправлять отчёты по расписанию — всё это задачи на несколько минут.

Создание приложений

Сделать простой веб-сайт, Telegram-бота, личный дашборд с данными, инструмент для своего бизнеса — без найма разработчика и без изучения языков программирования.

Работа с данными

Обработать большой CSV-файл, найти паттерны, построить график, преобразовать данные из одного формата в другой — Claude разберётся сам.

Прототипирование идей

Быстро проверить идею: описать что хотите — получить работающий прототип за час, а не за месяц.

Как выбрать задачу для автоматизации

Хорошая задача для Claude Code — та, которую вы делаете регулярно, она занимает время, имеет чёткий результат и не требует творческих решений в процессе. Спросите себя:

  • Делаю ли я это каждую неделю или чаще?
  • Можно ли описать правило, по которому это делается?
  • Есть ли у задачи понятный результат — файл, таблица, сообщение?
  • Мне скучно это делать вручную?

Если ответили «да» хотя бы на три — это хорошая задача для автоматизации.

02 / Что такое Claude и его режимы

Claude — AI-агент от компании Anthropic. В отличие от обычных чат-ботов, он умеет не только отвечать на вопросы, но и самостоятельно выполнять задачи на вашем компьютере: создавать и редактировать файлы, запускать программы, подключаться к серверам.

Режимы работы

Режим чата

Обычная переписка — задаёте вопрос, получаете ответ. Работает как ChatGPT, но модели Claude часто точнее и детальнее. Идеально для старта: пробуйте 2–3 дня бесплатно вместо ChatGPT.

Режим агента — Cowork

Агент управляет вашим компьютером: открывает браузер, работает с файлами, запускает программы. Вы описываете задачу — он её выполняет. Очень мощный режим, особенно в связке с плагинами.

Режим Claude Code

Специальный режим для написания программ и автоматизации. Запускается отдельно — через терминал или как расширение в редакторе кода. Пишет, запускает и исправляет код, создаёт и удаляет файлы.

Режим в IDE (VS Code и другие)

Для тех, кто работает с редакторами кода. Claude запускается внутри редактора и выполняет всё, что раньше делали программисты вручную.

Режим терминала

Прямая работа через командную строку. Нужен для системных задач — проверить страну подключения или установить зависимости. Используется редко и только для конкретных команд.

03 / Плагин feature-dev — зачем он нужен

Feature-dev — официальный плагин от Anthropic для Claude Code. Это самый важный плагин для тех, кто хочет создавать приложения и автоматизировать задачи. Без него Claude просто пишет код по вашему запросу. С ним — проводит вас через структурированный процесс разработки, как опытный технический руководитель.

В чём проблема без плагина

Когда вы просто пишете Claude «сделай мне приложение X» — он начинает писать код сразу, не разобравшись в деталях. В итоге: не учитываются ваши реальные требования, архитектура выбирается случайно, код получается нестабильным, и вы по кругу исправляете одно и то же. Feature-dev решает эту проблему структурой.

Как работает feature-dev: 7 фаз

Запускается одной командой: /feature-dev [описание задачи]. Дальше Claude ведёт вас через семь шагов, останавливаясь на каждом для вашего подтверждения:

  • Фаза 1: Исследование. Claude изучает вашу задачу, уточняет цели, определяет заинтересованных лиц и ограничения. Формирует чёткий список критериев приёмки — что именно должно работать в результате.
  • Фаза 2: Изучение кодовой базы. Если у вас уже есть проект — Claude читает существующий код, понимает структуру и находит, куда встроить новую функцию. Для новых проектов — выбирает подходящую архитектуру.
  • Фаза 3: Уточняющие вопросы. Claude задаёт конкретные вопросы о деталях реализации. Это важный шаг — ответив на них, вы избегаете ситуации «сделал не то, что я имел в виду».
  • Фаза 4: Проектирование архитектуры. Создаёт конкретные артефакты: схему API, модель данных, последовательность шагов, разбивку задач по приоритету, пользовательские сценарии.
  • Фаза 5: Реализация. Пишет код, создаёт тесты, готовит описание для pull request. Работает по чёткому плану, а не наугад.
  • Фаза 6: Проверка качества. Специальный агент-ревьюер проверяет код по чеклисту, сравнивает результат с критериями приёмки из фазы 1, выдаёт список приоритетных исправлений.
  • Фаза 7: Итоговое резюме. Полный отчёт о том, что сделано, что осталось, какие задачи стоит решить следующими.

Как установить feature-dev

В Claude Code нажмите «+» → Plugins → введите feature-dev → установите. На Mac потребуется Git (установка через терминал, команда есть в официальной инструкции). После установки команда /feature-dev будет доступна в любом проекте.

04 / VPN — обязательное условие

Claude официально недоступен в России, Китае и ряде других стран. Без VPN или с неправильным VPN аккаунт заблокируют без объяснений. Деньги вернут через 3–4 дня, аккаунт восстановить невозможно.

Почему обычный прокси не работает

Прокси (встроенный в браузер или расширения) меняет IP только для браузера. Когда Claude Code запускается как отдельная программа, он обращается к серверам Anthropic напрямую — через ваш реальный российский IP. Нужен полноценный VPN-клиент, который перенаправляет весь трафик системы.

Как проверить, что VPN работает правильно

  1. Включите VPN и откройте браузер.
  2. Зайдите на 2ip.ru или whatismyip.com — страна должна быть не Россия.
  3. Откройте терминал, выполните команду проверки IP из инструкции к Claude Code.
  4. Страна в терминале должна совпадать с браузером.
  5. Только тогда можно запускать Claude Code.
⚠ Kill Switch

Если VPN поддерживает Kill Switch — включите. Он блокирует весь трафик, если VPN вдруг отключился. Без него Claude Code может успеть отправить запрос с российского IP.

Системный проксиЧастично, не все программыНЕТ

05 / Автозапуск — обязательно выключить

По умолчанию Claude Code прописывает себя в автозагрузку. Когда компьютер включается, он стартует раньше VPN и обращается к серверам Anthropic с российского IP. На серверах копится история смены адресов — аккаунт блокируется автоматически.

  1. Откройте Claude Code.
  2. Перейдите в настройки (Settings).
  3. В первом пункте меню найдите опцию запуска при старте системы.
  4. Выключите её. Перезагрузите компьютер и убедитесь, что Claude Code не запустился сам.
⚠ Правило: сначала VPN, потом Claude Code

Всегда сначала включаете VPN и проверяете страну — и только потом открываете Claude Code. Никогда не запускайте Claude Code с выключенным VPN, даже «на секунду».

06 / Аккаунт и подписка

Подписки продаются через посредников в разрешённых странах — это нормально и работает. Но есть правила, нарушение которых приводит к мгновенной блокировке.

Правильный порядок

  1. Создайте бесплатный аккаунт на claude.ai.
  2. 2–3 дня используйте Claude в режиме чата — это «прогрев» аккаунта.
  3. Только после этого подключайте платную подписку.
  4. Начинайте с базового плана, а не сразу с Max ($100).
⚠ При блокировке

Anthropic не объясняет причины и не восстанавливает аккаунты. Деньги возвращают через 3–4 дня. Все данные и проекты теряются. Единственный выход — новый аккаунт.

07 / Установка и первый запуск

Скачайте Claude Code с официального сайта Anthropic. Сразу после установки — до первого запуска — выключите автозапуск (раздел 05).

Рабочая папка

Claude работает в папке, которую вы указываете. В ней он создаёт и читает файлы. Для каждого нового проекта создавайте отдельную папку — это обязательно.

  1. Создайте папку (например: Документы/Проекты/Проект1).
  2. Откройте Claude Code и укажите папку как рабочую директорию.
  3. На вопрос «Доверяете каталогу?» — нажмите «Доверять».

Для Mac: нужен Git

При установке плагинов появляется «git is required». Откройте Terminal (Программы → Утилиты), вставьте команду установки из инструкции Claude Code, введите пароль Mac (символы не отображаются), нажмите Enter.

09 / Частые ошибки и решения

Запустил Claude Code без VPN — аккаунт заблокировали Причина

Запрос ушёл с российского IP.

Решение

На будущее — сначала VPN, потом Claude Code. Сейчас — ждать возврата 3–4 дня, создать новый аккаунт.

Купил подписку сразу — заблокировали через день Причина

Не было прогрева.

Решение

Новый аккаунт, 2–3 дня в режиме чата, потом подписка.

Claude Code запускается сам при включении компьютера Причина

Не выключен автозапуск.

Решение

Настройки → первый пункт меню → выключить.

VPN включён, но терминал показывает Россию Причина

VPN работает только для браузера.

Решение

Использовать полноценный VPN-клиент.

На Mac ошибка «git is required» Решение

Terminal → вставить команду установки из инструкции Claude Code → ввести пароль Mac → Enter.

/feature-dev не работает после установки плагина Решение

Убедитесь, что выбрана рабочая папка. Перезапустите Claude Code. Если проблема осталась — переустановите плагин через «+» → Plugins.
